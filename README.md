# Reseller Pro 3w1 (PWA Web App)

W 100% samodzielna, mobilna aplikacja internetowa (PWA) działająca w przeglądarce smartfona bez konieczności uruchamiania jakiegokolwiek komputera.

* **Live URL:** https://cyberpolak99.github.io/reseller-pro/
* **Model AI:** Google Gemini 3.5 Flash Lite
* **Obsługiwane platformy:** Vinted, OLX, Allegro Lokalnie
* **Funkcje:**
  * Weryfikacja stanu i kompletności ze zdjęć
  * Wycena rynkowa z buforem negocjacyjnym +15-20%
  * Tytuł z zakazem słów pisanych ALL-CAPS (max 70 znaków)
  * Czysty tekst opisu bez Markdown (**) + 20 dopasowanych hashtagów
  * Kopiowanie do schowka 1 dotknięciem
  * Bezpośrednie linki do wystawiania na platformach
