# Reseller Pro 3w1 (PWA Web App - Master Edition)

W 100% samodzielna, mobilna aplikacja internetowa (PWA) działająca w przeglądarce smartfona bez konieczności uruchamiania jakiegokolwiek komputera.

* **Live URL:** https://cyberpolak99.github.io/reseller-pro/
* **Model AI:** Google Gemini 3.5 Flash Lite
* **Obsługiwane platformy:** Vinted, OLX, Allegro Lokalnie
* **Metodologia:** Karol Pilarz (Poradnik Handlowca Master Edition)

### Funkcje:
* **Weryfikacja ze zdjęć:** Automatyczne odczytywanie modelu, tabliczek znamionowych, metek i stanu opakowania bezpośrednio z aparatu telefonu.
* **Strategia 3 Cen:** Wycena rynkowa z automatyczną siatką cenową (cena wyjściowa z buforem +15-20%, realny cel 100% oraz sztywne minimum stop-loss).
* **Tarcza Anty-Ban 5 Kategorii (Vinted TOS Guard):** Aktywna ochrona przed banem i shadowbanem (blokowanie zwrotów komercyjnych/hurtowych, obejść płatności BLIK/WhatsApp, słów zakazanych Allegro, podróbek i niedozwolonych artykułów).
* **Tytuł SEO:** Zgodny ze standardem OLX/Allegro (max 70 znaków) z wymuszeniem braku słów pisanych samymi wielkimi literami (ALL-CAPS).
* **Czysty opis:** Profesjonalny tekst bez gwiazdek Markdown (`**`), bez emotikonów psujących formatowanie, z dokładnie 20 dopasowanymi hasztagami.
* **Skrypt negocjacji na czat:** Gotowa odpowiedź zbijająca zbyt niskie oferty kupujących (obrona marży).
* **Ergonomia mobilna:** Kopiowanie tytułu, opisu i wiadomości 1 dotknięciem + bezpośrednie kafelki przekierowujące do formularzy wystawiania na Vinted, OLX i Allegro Lokalnie.
